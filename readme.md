# Git & GitHub: strumenti di collaborazione

Mini progetto in HTML, CSS e JavaScript vanilla, creato come esercizio per lavorare con Git e GitHub. La pagina mostra un testo e un pulsante che permette di nasconderlo o mostrarlo.

## Funzionalità

- Il pulsante nasconde o mostra il paragrafo di testo.
- L'etichetta del pulsante cambia in base allo stato (`Nascondi testo` / `Mostra testo`).
- Il pulsante ha un effetto hover con inversione dei colori.

## Struttura del progetto

```
.
├── index.html   # Struttura della pagina
├── style.css    # Stili
├── app.js       # Logica mostra/nascondi
└── README.md    # Documentazione
```

## Come eseguire il progetto

Non servono dipendenze né build.

1. Clona il repository:
   ```bash
   git clone https://github.com/<tuo-username>/<nome-repo>.git
   ```
2. Apri `index.html` nel browser.

## Pubblicazione con GitHub Pages

1. Vai su **Settings → Pages** nel repository.
2. Seleziona **Deploy from a branch**, branch `main`, cartella `/ (root)`.
3. Il sito sarà disponibile su `https://<Catherine NTANDA>.github.io/<ntanda-repo>/`.
